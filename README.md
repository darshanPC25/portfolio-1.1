# Darshan Portfolio

Personal developer portfolio and private visual CMS for Paridarshan Sahoo (Darshan).

| Part        | Directory   | Status                          | URL                     |
| ----------- | ----------- | ------------------------------- | ----------------------- |
| Frontend    | `frontend/` | Public site built (Batch 1)     | http://localhost:5173   |
| Backend     | `backend/`  | Not started                     | http://localhost:8080   |
| Database    | `database/` | Not started                     | localhost:5432          |

The frontend and backend are independent applications that communicate over REST.

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

See [frontend/README.md](frontend/README.md) for details.
